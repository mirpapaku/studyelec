# 전기기사 기출문제 통합 분리형 PWA 배포 가이드

## 1. 구성 요약
- 총 51개 원본 HTML → **170개 회차별 분리 JSON** (총 16,905문항, 회차당 최대 288KB)
- **중복 회차 교차 검증**: 37개 연도·회차 그룹에서 출처별(김영북스, 한솔아카데미, 다산에듀, 테스트나라, 핵담, 전기요금, 파워텔, 엔지니어랩, 엔트, 전자문제집) 원문을 나란히 비교 가능
- **2003~2008년 미해설 회차(18개)**: `hasExplanation: false`로 통합 완료. 추후 해당 JSON 파일만 교체하면 자동 반영
- **도면 이미지 최적화**: 중복 제거된 2,125개 이미지를 `assets/img/`로 분리해 아이폰 13 미니에서도 가볍게 구동

## 2. 명령어(cmd) 없이 1분 만에 무료로 올리는 법 (Cloudflare Pages 추천)
1. 이 ZIP 파일의 압축을 한 폴더에 풉니다.
2. https://dash.cloudflare.com 에 무료 가입/로그인합니다.
3. 좌측 메뉴 **Workers & Pages** → **Create** → **Pages** 탭 → **Direct Upload(직접 업로드)** 선택.
4. 프로젝트 이름(예: `electric-cbt`) 입력 후, 압축 푼 폴더를 통째로 드래그 앤 드롭하고 **Deploy site** 클릭.
5. 생성된 `https://electric-cbt.pages.dev` 주소로 PC, 샤오신패드 12.7, 아이폰 13 미니에서 접속합니다.

## 3. 3대 기기 오프라인 세팅 방법
- **아이폰 13 미니**: 사파리로 접속 → 하단 공유 버튼 → **홈 화면에 추가** → 앱 실행 후 상단 **'오프라인 저장'** → **'JSON + 도면 이미지 전체 저장'** 클릭.
- **샤오신패드 12.7 / PC**: 크롬(또는 엣지)으로 접속 → 주소창 설치 아이콘(또는 메뉴 '홈 화면에 추가') → 상단 **'오프라인 저장'** 클릭.
