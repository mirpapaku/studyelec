# ⚡ 전기기사 필기+실기 완전통합 PWA v5 배포 가이드

## 1. 구성 요약 (`studygas` 구조 기반 · 노란색 테마)
- **필기 통합 DB**: 16,706문항 (2003~2026년 · 10개 출처 · KaTeX 수식 · 도면 2,126장)
- **실기 4대 교재 통합**: 2,928문항 (2008~2026년 · 다산/한솔/서울공과/테스트나라 167회차 · 도면 WebP 최적화 2,021장, 200.7MB → 33.6MB)
- **4개 메인 탭**: `📝 필기 (16,706)` / `🔧 실기 (2,928)` / `🔗 필기+실기 함께` (짝꿍 묶음·교차 배치) / `📖 전트키 이론` (208개 치트키)
- **필기↔실기 양방향 연계**: 필기 카드의 `⚡ 실기연계 N건 ▾` 클릭 또는 상단 `🔗 실기연계 자동펼침`으로 실기 기출·정답·해설을 바로 펼쳐서 학습
- **실기 단답 PDF 공간**: 상단 `📄 단답PDF` 및 실기 필터 내 전용 배너에서 추후 단답 PDF를 기기(IndexedDB)에 연결해 오프라인 열람 가능
- **Network-First 서비스 워커 (`sw.js`)**: 재배포 시 구버전 캐시 충돌 없이 즉시 최신 화면 반영

## 2. Cloudflare Pages 무료 배포 방법
1. 압축을 한 폴더에 풉니다.
2. `https://dash.cloudflare.com` → **Workers & Pages** → **Create** → **Pages** → **Direct Upload**.
3. 폴더를 통째로 드래그 앤 드롭 후 **Deploy site** 클릭.
