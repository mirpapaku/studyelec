# 전기기사 필기·실기 통합 CBT PWA v4 배포 가이드

## 1. v4 주요 추가 기능
- **독립 `실기 기출 + 단답` 탭 추가**: 기존 전트키(`이론(치트키) + 기출`)와 별개로 실기 4대 교재(다산에듀, 한솔아카데미, 서울공과학원, 테스트나라) **167개 회차 / 2,928문항** 통합
- **실기 도면 WebP 최적화**: 원본 PNG 2,040장(200.7MB) → 중복 제거 WebP 2,021장(**33.6MB**, 83.2% 용량 절감)으로 경량화하여 모바일 PWA 오프라인 캐시에 최적화
- **필기 ↔ 실기 양방향 연계**:
  - 필기 문제 풀이 중(1문제씩 / 20문제 모아보기) 실기와 연계된 문항(8,001문항, 24개 핵심 토픽)에 **`⚡ 실기 연계`** 배지 표시 → 클릭 시 현재 화면 위 **미리보기 팝업**에서 실기 문제·도면·정답·해설 바로 확인 및 해당 실기 회차로 즉시 이동
  - 실기 풀이 화면에서는 반대로 **`📖 연계 필기 치트키`** 버튼으로 기초 이론 치트키로 역이동 가능
- **실기 단답 PDF 준비 공간**: 실기 탭 상단 및 실기 풀이 화면 상단에 별도의 **단답 PDF 연결 공간(IndexedDB)** 마련 (추후 단답 정리 PDF를 브라우저에서 바로 연결해 오프라인 열람 가능)

## 2. Cloudflare Pages 무료 배포 방법
1. 이 ZIP 파일의 압축을 한 폴더에 풉니다.
2. `https://dash.cloudflare.com` 로그인 → **Workers & Pages** → **Create** → **Pages** → **Direct Upload**.
3. 압축 푼 폴더를 통째로 드래그 앤 드롭하고 **Deploy site** 클릭.
4. 생성된 주소로 PC, 샤오신패드, 아이폰에서 접속 후 상단 **'오프라인 저장'**에서 원하는 옵션(필기만 / 필기+실기 전체)을 선택해 저장합니다.
